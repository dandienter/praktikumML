# Praktikum Mingguan

Kumpulan notebook (`.ipynb`) praktikum mingguan untuk 14 bab, siap dibuka di Google Colab.
Tiap notebook mulai dari bagian Implementasi Python (tanpa ringkasan konsep), sudah ada outputnya,
dan bisa langsung dijalankan dengan **Runtime > Run all**. Sel setup Colab ikut disertakan
agar file data terunduh otomatis.

| File | Bab |
|------|-----|
| praktikum-bab-01.ipynb | Konsep Dasar Machine Learning |
| praktikum-bab-02.ipynb | Workflow CRISP-DM, Bias-Variance |
| praktikum-bab-03.ipynb | Data Preparation |
| praktikum-bab-04.ipynb | Feature Engineering & Pipeline |
| praktikum-bab-05.ipynb | Decision Tree & Pruning (isi: kode modul 5.11 lengkap + penjelasan siap presentasi) |
| praktikum-bab-06.ipynb | KNN & Naive Bayes |
| praktikum-bab-07.ipynb | Evaluasi Model |
| praktikum-bab-08.ipynb | Support Vector Machine |
| praktikum-bab-09.ipynb | Ensemble Methods |
| praktikum-bab-10.ipynb | Clustering |
| praktikum-bab-11.ipynb | PCA / Reduksi Dimensi |
| praktikum-bab-12.ipynb | Neural Networks |
| praktikum-bab-13.ipynb | Convolutional Neural Networks |
| praktikum-bab-14.ipynb | Mini Project End-to-End |

File `latihan-5-1-pre-pruning.ipynb` adalah notebook khusus Latihan 1 (bagian 5.1) Bab 5: grid search pre-pruning.
