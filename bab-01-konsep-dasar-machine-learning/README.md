# Bab 1: Konsep Dasar Machine Learning

## Tujuan
Memahami definisi, kategori, dan tahapan kerja Machine Learning melalui alur end-to-end paling sederhana (dataset Iris + KNN).

## Isi
- `praktikum-bab-01.ipynb` - notebook praktikum (sudah dieksekusi, lengkap dengan output & visualisasi)
- `praktikum-bab-*.pdf` - versi PDF bergaya modul

## Sumber Data
`sklearn.datasets.load_iris` (dataset publik Iris: 150 baris, 4 fitur, 3 spesies). Tidak ada file yang perlu diunduh.

## Cara Menjalankan
1. Buka `praktikum-bab-01.ipynb` di Google Colab atau Jupyter Notebook lokal.
2. Jalankan cell berurutan dari atas ke bawah (Run All).
3. Dataset dimuat langsung dari `sklearn.datasets.load_iris` - tidak perlu mengunduh apa pun.
